# 生态系统模拟系统

一个用 C++ 面向对象写的简易水域生态模拟：大鱼在水里捕食小鱼，鱼随机游动、消耗能量，
过完一天打印一次地图和存活情况。

## 功能概览

- **二维水域**：20 × 10 的网格，鱼游出边界会从对面绕回来（环形地图，永远游不丢）
- **按天推进**：每天固定 3 步，每一步鱼都会随机游动并消耗 1 点能量
- **大鱼捕食**：大鱼和猎物距离不超过 1 格就能咬到，吃掉后恢复能量
- **三种死法**：被吃掉、能量耗尽饿死、年龄到上限老死
- **死亡即清理**：死掉的生物立刻从世界里移除，同时释放内存（不泄漏）
- **事件有才汇报**：发生事情才打印，没事件就安静跳过；每天结束打印地图 + 存活数量

## 目录结构

| 文件 | 说明 |
| --- | --- |
| `Organism.h` / `Organism.cpp` | 生物基类：存活状态、年龄、死亡 |
| `Fish.h` / `Fish.cpp` | 鱼：坐标、速度、能量，二维随机游动；同时定义地图尺寸 |
| `bigFish.h` / `bigFish.cpp` | 大鱼：捕食者，会吃掉附近的小鱼 |
| `smallFish.h` / `smallFish.cpp` | 小鱼：猎物，被吃掉时提供能量 |
| `World.h` / `World.cpp` | 世界：管理所有生物、推进时间、捕食判定、清理与汇报 |
| `main.cpp` | 程序入口：放鱼、按天推进模拟 |
| `CMakeLists.txt` | 构建配置：列出所有源文件，供 CLion / CMake 编译整个项目 |

## 类设计

```
Organism                 生物基类：alive / age / age_max
   └── Fish              鱼：x / y / speed / energy，负责游动
         ├── bigFish     大鱼（捕食者）
         └── smallFish   小鱼（猎物）
```

`World` 里用 `std::vector<Organism*>` 保存所有生物，靠基类指针统一调用虚函数，
所以以后再加新生物（比如水草）不用改动 `World` 的循环。

基类 `Organism` 提供了一组带默认实现的接口，子类只覆写自己关心的那几个：

| 接口 | 作用 | 谁覆写了 |
| --- | --- | --- |
| `getX()` / `getY()` | 读取坐标 | `Fish` |
| `foodValue()` | 被吃掉能提供多少能量，返回 0 表示不能吃 | `smallFish`（返回 3） |
| `tryEat(other)` | 尝试吃掉对方，成功返回 true | `bigFish` |
| `kill()` | 立刻结束生命 | 用基类默认实现 |
| `name()` | 事件播报时显示的名字 | 大鱼 / 小鱼 |
| `symbol()` | 画地图时用哪个字符 | 大鱼 `B` / 小鱼 `s` |

## 核心机制

### 1. 时间

一天 = 3 步。`World::step()` 每被调用一次就推进"一步"，
走满 3 步算过完一天，自动打印一次地图和存活情况，然后进入下一天。

### 2. 游动（`Fish::update()`）

每一步按顺序做三件事：

1. 年龄 +1（由父类处理，到上限就老死）
2. 能量 −1；归零就饿死
3. 随机游动：方向和步数都是随机的
   - 方向：`dx`、`dy` 各在 −1 ~ 1 之间随机取，但不能同时为 0
   - 步数：随机走 1 ~ `speed` 格
   - 坐标用取模运算实现环形绕回

`speed` 越大平均走得越远，所以大鱼（速度 2）比小鱼（速度 1）游得快，更容易追上猎物。

### 3. 捕食（`bigFish::tryEat()`）

- 先看对方的 `foodValue()`：返回 0 表示不能吃（大鱼自己就是 0，所以不会同类相食）
- 再用**切比雪夫距离**判断远近，也就是横、纵坐标差值的最大值，`≤ 1` 就算够得着
- 咬中后调用 `other->kill()` 干掉猎物，自己恢复固定 3 点能量

捕食判定放在所有生物都移动完之后统一进行，避免"谁先被遍历到谁就占便宜"。

### 4. 能量与死亡

| 死亡原因 | 触发条件 |
| --- | --- |
| 被吃掉 | 被大鱼咬中，`kill()` 直接置为死亡 |
| 饿死 | 能量每步 −1，归零即死 |
| 老死 | 年龄每步 +1，达到寿命上限即死 |

死后由 `World::removeDead()` 统一 `delete` 并从容器中移除，
既做了统计上的"清理"，也避免了内存泄漏。

## 参数速查

| 生物 | 地图符号 | 寿命 | 速度 | 初始能量 | 被吃提供能量 |
| --- | --- | --- | --- | --- | --- |
| 大鱼 | `B` | 35 | 2 | 35 | 不可食用 |
| 小鱼 | `s` | 30 | 1 | 30 | 3 |

地图符号：`.` 表示水域，`B` 表示大鱼，`s` 表示小鱼。

## 运行方法

### 一、获取代码

本仓库使用 **SSH** 方式连接 GitHub（HTTPS 直连在本机网络环境下不稳定，经常超时连不上）。

```bash
# SSH 方式（本项目当前使用的连接方式）
git clone git@github.com:kawhi-chanzi/-.-.git ecosystem
cd ecosystem

# HTTPS 方式（备用）
git clone https://github.com/kawhi-chanzi/-.-.git ecosystem
```

> 仓库原名是 `-.-`，直接克隆会得到一个叫 `-.-` 的目录，在命令行里很不好操作，
> 所以上面多加了一个 `ecosystem` 参数，把克隆下来的目录名改成 `ecosystem`。

换一台电脑用 SSH 克隆，需要先配置 SSH 密钥：

1. 生成密钥：`ssh-keygen -t ed25519 -C "你的邮箱"`
2. 把 `~/.ssh/id_ed25519.pub` 的内容**整行**复制到 GitHub → Settings → SSH and GPG keys → New SSH key
3. 测试连接：`ssh -T git@github.com`，看到 `Hi xxx! You've successfully authenticated` 就说明配好了

Windows 下如果 git 报 `Host key verification failed`，是因为 git 自带的 SSH 没配置过主机密钥，
让 git 改用系统自带的 OpenSSH 就行：

```bash
git config --global core.sshCommand "C:/Windows/System32/OpenSSH/ssh.exe"
```

### 二、编译

本项目只有 6 个 `.cpp` 文件，一条命令就能编译完，不需要额外的构建工具。

**方式一：命令行（g++ / MinGW）**

```bash
g++ -std=c++17 main.cpp Organism.cpp Fish.cpp bigFish.cpp smallFish.cpp World.cpp -o ecosystem
```

Windows 下如果运行时中文显示乱码，加上编码参数，指定源码和可执行文件都用 UTF-8：

```bash
g++ -std=c++17 -finput-charset=UTF-8 -fexec-charset=UTF-8 main.cpp Organism.cpp Fish.cpp bigFish.cpp smallFish.cpp World.cpp -o ecosystem
```

**方式二：CLion**

项目根目录带了一份 `CMakeLists.txt`，所以用 CLion 直接「Open」**项目根目录**即可：

1. `File → Open`，选中项目根目录（不要只单独打开某个 `.cpp` 文件）
2. CLion 会自动识别成 CMake 项目并建立索引，右上角的运行按钮就能直接用了
3. 如果按钮还是灰的，点提示条上的 `Load CMake Project`，或者 `Tools → CMake → Reload CMake Project`

> ⚠️ `CMakeLists.txt` 里列着所有源文件。以后新增 `.cpp` 文件，
> 一定要把它加进 `add_executable(...)` 的清单，否则它不会被编译，
> 链接时就会报一堆 `undefined reference`。
>
> 顺带一提：CLion 自带 cmake，所以本机即使没装 cmake 也能正常构建。

### 三、运行

```bash
./ecosystem          # Linux / macOS / Git Bash
.\ecosystem.exe      # Windows PowerShell / CMD
```

程序会连续模拟 10 天、每天 3 步，在控制台打印捕食事件、水域地图和每日存活数量。

## 已知限制与可扩展方向

- **小鱼只减不增**：目前没有繁殖机制，长期跑下去小鱼会被大鱼吃光
- **"吃鱼续命"尚未生效**：大鱼初始能量（35）正好等于寿命（35），两者同时耗尽，
  所以吃不吃都活到 35 步。把大鱼的初始能量调小（比如 25），
  不吃的会先饿死、吃到的才能活满寿命
- **可扩展**：繁殖（能量足够时产卵）、水草 / 浮游生物（给小鱼提供食物）、
  大鱼主动追击最近的猎物、把参数抽到配置文件里
