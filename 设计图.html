二、核心函数流程图 (World::step())

flowchart TD
    A([开始 step]) --> B[遍历所有生物]
    B --> C{生物是否存活?}
    C -- 否 --> B
    C -- 是 --> D[c->update()
移动+消耗能量+年龄增长]
    D --> E{update后是否死亡?}
    E -- 是 --> F[记录事件: XX死亡]
    E -- 否 --> G
    F --> G[遍历所有捕食者 eater]
    G --> H{eater 已死?}
    H -- 是 --> G
    H -- 否 --> I[遍历所有 other 生物]
    I --> J{eater == other?}
    J -- 是 --> I
    J -- 否 --> K{eater->tryEat(other)?}
    K -- 成功 --> L[记录事件: 大鱼吃掉了小鱼]
    K -- 失败 --> I
    L --> M
    M[removeDead()
删除死亡生物+释放内存] --> N[stepInDay++]
    N --> O[reportEvents()
有事件则打印]
    O --> P{stepInDay >= 3?}
    P -- 否 --> Q([结束本次step])
    P -- 是 --> R[show()
打印地图+存活统计]
    R --> S[stepInDay=0, day++]
    S --> Q

三、类间关系说明

  • 继承体系：Organism（生物基类）→ Fish（鱼类）→ smallFish（小鱼）/ bigFish（大鱼），三层继承体现面向对象的层次化设计。
  • 多态机制：基类 Organism 定义了 update()、tryEat()、foodValue()、symbol() 等虚函数，子类按需覆写。World 只持有 Organism* 基类指针，调用时自动分派到对应子类实现。
  • 聚合关系：World 通过 vector<Organism*> 聚合多个生物对象，生物可以独立于 World 存在，生命周期由 World 统一管理（析构时全部释放）。
